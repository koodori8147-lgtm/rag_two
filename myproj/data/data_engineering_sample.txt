데이터 엔지니어링 학습 예제 문서

1. 데이터 수집
데이터 엔지니어는 여러 시스템에서 데이터를 수집합니다.
수집 대상에는 데이터베이스, API, 로그 파일, CSV 파일 등이 있습니다.
수집된 데이터는 이후 처리와 분석을 위해 저장됩니다.

2. 데이터 전처리
수집한 데이터에는 결측값, 중복값, 잘못된 형식이 포함될 수 있습니다.
전처리 과정에서는 데이터를 정제하고 필요한 형식으로 변환합니다.
Python과 Pandas는 데이터 전처리에 자주 사용됩니다.

3. ETL 파이프라인
ETL은 Extract, Transform, Load의 약자입니다.
Extract 단계에서는 원본 데이터를 가져옵니다.
Transform 단계에서는 데이터를 정제하고 변환합니다.
Load 단계에서는 처리된 데이터를 데이터베이스나 데이터 웨어하우스에 저장합니다.

4. 데이터베이스
관계형 데이터베이스에서는 SQL을 사용하여 데이터를 조회하고 수정합니다.
대표적인 관계형 데이터베이스에는 MySQL, PostgreSQL, Oracle 등이 있습니다.
대용량 데이터 환경에서는 데이터 웨어하우스와 데이터 레이크도 자주 사용됩니다.

5. RAG와 문서 로딩
RAG는 외부 문서를 검색한 뒤 검색 결과를 LLM의 답변 생성에 활용하는 방식입니다.
LangChain의 TextLoader를 이용하면 txt 파일을 Document 객체로 불러올 수 있습니다.
불러온 문서는 필요에 따라 여러 조각으로 나누고 임베딩한 뒤 벡터 데이터베이스에 저장할 수 있습니다.

6. 간단한 질문 예시
