# 설비 운영 매뉴얼

이 문서는 생산 설비의 기본 운전과 점검 절차를 설명합니다.

## 1. 기동 절차

설비 전원을 투입하기 전에 주변 작업 환경을 확인합니다.
비상 정지 버튼이 해제되어 있는지 확인하고 설비 내부에 작업자가 없는지 확인합니다.

### 1.1 전원 확인

메인 전원 표시등이 정상인지 확인합니다.
제어반의 알람 메시지가 없는지 확인합니다.

### 1.2 초기화

HMI 화면에서 초기화 버튼을 선택합니다.
축 위치와 센서 상태가 기준 범위에 들어오는지 확인합니다.

## 2. 생산 운전

생산 레시피를 선택한 뒤 제품 정보를 입력합니다.
설비 속도와 주요 공정 조건이 작업 표준과 일치하는지 확인합니다.

### 2.1 공정 조건

정상 온도 범위는 40도에서 70도입니다.
진동 경고 기준은 5.0 mm/s입니다.
압력 기준은 0.95 bar에서 1.05 bar입니다.

### 2.2 생산 중 점검

30분마다 온도와 진동 값을 확인합니다.
경고가 발생하면 설비 ID, 발생 시각, 센서 값을 기록합니다.

## 3. 이상 발생 대응

설비에서 경고가 발생하면 즉시 상태를 확인합니다.
경고 원인에 따라 생산 지속 여부를 판단합니다.

### 3.1 온도 경고

온도가 75도 이상이면 냉각 상태와 베어링 상태를 확인합니다.
온도가 계속 상승하면 설비를 정지하고 정비 담당자에게 연락합니다.

### 3.2 진동 경고

진동이 5.0 mm/s 이상이면 체결 상태와 회전체 상태를 점검합니다.
온도 상승이 동시에 발생하면 우선순위를 높여 점검합니다.

## 4. 정지 절차

생산 중인 제품이 모두 배출된 것을 확인합니다.
자동 운전을 종료하고 메인 전원을 차단합니다.

### 4.1 종료 기록

최종 생산 수량과 불량 수량을 기록합니다.
설비 알람 이력을 저장하고 특이사항을 교대자에게 전달합니다.
